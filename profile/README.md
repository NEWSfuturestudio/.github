### 👋 关于我们 (About Us)

**NEWSfuturEStudio** 是一群充满极客精神的开发者创建的科技工作室。

我们的项目方向很“杂”，但我们有一个极其专一的核心理念：**做开源生态的“补丁”**。

在这个时代，我们不缺庞大的框架，却常常找不到一个趁手、轻量、专注解决具体痛点的工具。我们致力于发现现有开源软件的不足，并开发安全、好用、优雅的替代方案来弥补这些欠缺。我们不屑于重复造轮子，我们只造那些真正缺失、或者不够完美的轮子。
